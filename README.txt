  SUBWAY RUNNER 3D feat. HATSUNE MIKU
  Godot 4.3 | 2026
============================================================

┌─ 游戏特色 ─────────────────────────────────────┐
│                                                    │
│  ［初音未来 3D 角色］ 真实 MMD 模型转换           │
│  ［KayKit 城市建筑］ 41 栋 3D 建筑 + 街灯/长椅     │
│  ［站酷黄油字体］ 可爱圆体艺术字 UI               │
│  ［日系游戏音效］ 小森平 CC0 专业音效库           │
│  ［动态 BGM 系统］ 自定义 MP3 背景音乐            │
│                                                    │
└────────────────────────────────────────────────────┘

┌─ 如何运行 ─────────────────────────────────────┐
│                                                    │
│  1. 下载 Godot 4.3 +                             │
│     https://godotengine.org/download               │
│                                                    │
│  2. Godot → 导入 → 选择 project.godot              │
│                                                    │
│  3. 右键 assets/models/buildings/ → Reimport       │
│     等待导入完成                                   │
│                                                    │
│  4. 按 F5 运行                                     │
│                                                    │
└────────────────────────────────────────────────────┘

┌─ 操作方式 ─────────────────────────────────────┐
│                                                    │
│  ← → / A D          切换轨道                      │
│  ↑ / W / 空格       跳跃                          │
│  ↓ / S              滑铲                          │
│  P                  暂停                          │
│  触控滑动            换轨 / 跳跃 / 滑铲            │
│                                                    │
└────────────────────────────────────────────────────┘

┌─ 游戏玩法 ─────────────────────────────────────┐
│                                                    │
│  ［金币］ 收集增加分数，连击加分                   │
│  ［宝石］ 稀有紫色宝石，500 分/个                  │
│  ［护盾］ 蓝色道具，抵挡 1 次撞击                  │
│  ［磁铁］ 粉色道具（引力范围扩大）                 │
│  ［双倍分］ 金色道具，10 秒 2 倍分数               │
│  ［里程碑］ 每 1000 米额外加分 + 特效              │
│  ［连击］ 连续收集金币增加 combo 倍率              │
│                                                    │
└────────────────────────────────────────────────────┘
