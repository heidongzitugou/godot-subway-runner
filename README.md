# 地铁疾跑 3D — Subway Runner 3D

A 3D endless runner game built with Godot 4.3, featuring Miku-themed aesthetics.

🎮 **Play Online**: https://heidongzitugou.github.io/godot-subway-runner/

## Controls

| Key | Action |
|-----|--------|
| ← → / A D | Switch lanes |
| ↑ / W / Space | Jump |
| ↓ / S | Slide |
| P | Pause |

## Development

Built with [Godot 4.3](https://godotengine.org/).

### Export for Web

```bash
godot --headless --path . --export-release "Web"
```
